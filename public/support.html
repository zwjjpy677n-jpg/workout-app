Web 版の記録をアプリに引っ越したい
  1. Web 版（Safari やホーム画面の GRIND）で「管理 → バックアップ → エクスポート」を押し、ファイルに保存します。
  2. アプリで「管理 → バックアップ → インポート」を押し、さっきのファイルを選びます。

インポートすると、アプリの中の記録は書き出したファイルの内容に置き換わります。

記録のバックアップを取りたい

「管理 → バックアップ → エクスポート」を押すと共有画面が出ます。「"ファイル"に保存」や AirDrop で保存してください。記録は端末の中だけにあるので、機種変更の前やアプリを消す前には必ず書き出してください。

友達と記録を共有したい
  1. 「友達」タブの「自分の記録を共有」を押し、LINE などで送ります。
  2. 受け取った人は、リンクを長押しして「コピー」し、「友達」タブの「リンクを貼り付けて追加」に貼り付けます。

コメントやメニューも同じ方法で送れます。体重・体脂肪率・メモは共有されません。

レスト終了の通知が来ない
  • iPhone の「設定 → 通知 → GRIND」で通知がオンになっているか確認してください。
  • アプリの「管理 → 設定 → レスト終了を音で知らせる」がオンになっているか確認してください。
  • アプリを開いているときは、通知の代わりに画面と音でお知らせします。
  • 集中モードがオンのときは、通知が届かないことがあります。
