COLOR

#0B0B0D 背景 #16161A カード #E10600 アクセント。赤は「押せる所・達成・強度」だけに使い、画面がうるさくならないようにします。

TYPE

数字は Oswald（コンデンス体）で大きく太く。日本語は Noto Sans JP。スポーツウォッチ/スコアボードの雰囲気。

前回の記録

記録中は各セット行に「前回」列を表示。種目名の下にも前回の日付とトップセットを表示し、超えるべき数字が一目で分かります。自己ベスト更新で PR バッジ。

カレンダー

トレーニング日は赤で塗りつぶし、ボリュームが大きい日ほど濃い赤（3段階）。日付タップでその日の内容を下に表示、編集へ。
