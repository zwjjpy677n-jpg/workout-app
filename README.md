# GRIND

アスリート向けの筋トレ記録アプリ（スマホ向けPWA）。データは端末のブラウザ内（IndexedDB）にのみ保存されます。

## 機能

- **8週間プログラム**: ホームに「N週目 / 8」。4・8週目は回復週（重さはそのまま、セット数を半分）。8週目にメイン種目の5RMと体重をテストして伸びを比較
- **曜日メニュー**: ルーティンに曜日とセット数・回数・メイン・上げ幅を設定。ホームの「今日のトレーニング」からワンタップで開始。参考メニュー（月 脚・筋力／火 上半身・筋肥大／水 脚・瞬発／金 上半身・瞬発）を最初から収録
- **おすすめ重量**: 前回の結果から「今回のおすすめ」と理由を表示（目標回数に届いたら上げ幅ぶん増やす、メイン種目はスピード低下も考慮）。色分けしたプレート図付き
- **開閉式の記録画面**: 種目ごとに開いて −/＋ で入力、セットごとに完了、「この種目を完了して次へ」
- **記録**: 重量×回数 / 自重(＋加重)×回数 / 時間 の3タイプ。RPE・セットメモ・ウォームアップ区別
- **前回の記録**: 種目ごとの前回トップセットと、セット行ごとの前回値（空欄で完了すると前回値を採用）
- **レストタイマー**: セット完了で種目ごとの秒数から自動スタート（±15秒・スキップ）
- **PR**: 自己ベスト（推定1RM 等）更新でバッジ表示
- **コンディション・メモ**: 睡眠/疲労感/やる気（1–5）とワークアウトメモ
- **カレンダー**: ボリュームに応じた3段階の色、日付タップで詳細・編集・削除
- **グラフ**: 推定1RM / 最大重量 / ボリューム / 最大加重 / 総回数 / 時間 / 体重の推移（1M/3M/1Y/ALL）
- **ホーム**: 今週の日数・ボリューム、部位別セット数、ルーティンからワンタップ開始、体重記録
- **ツール**: %1RM表、プレート計算（バー重量・使えるプレートは設定可能）
- **管理**: 種目（部位・タイプ・レスト秒）、ルーティン、体重履歴、設定、JSONバックアップ

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト（Vitest）
npm run lint     # 型チェック
npm run build    # 本番ビルド（dist/、PWA の service worker を含む）
npm run preview  # ビルド結果の確認
```

`dist/` は静的ファイルのみなので、GitHub Pages などにそのまま置けます（HashRouter・相対パス）。

## 公開（GitHub Pages）

`.github/workflows/deploy.yml` が main へのプッシュごとに 型チェック → テスト → ビルド → GitHub Pages へのデプロイ を行います（PR ではテストとビルドのみ）。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。公開URLは `https://<ユーザー名>.github.io/workout-app/` です。スマホで開いて「ホーム画面に追加」するとアプリとして使えます。

※ private リポジトリで Pages を使うには GitHub Pro 以上のプランが必要です。

## ルーティン（別アプリ）

毎日のルーティンと、その日のやることをチェックする自分用のアプリ。GRIND とは別のアプリで、データも端末内の別のデータベース（`routine`）に入ります。

- **今日**: 時間帯（朝／練習前／練習後／夜）ごとに今日やるルーティンを並べる。チェックだけの項目と、数値の項目（水 1500ml、睡眠 7.5時間など。目標に届くと自動でチェック）がある。上に達成率と連続日数
- **今日のやること**: その日だけのチェックリスト。前の日にできなかったものは「未完了が N 件あります」から選んで今日に持ち越せる
- **記録**: 日ごとの達成率をカレンダーの色で表示（日付を押すと後から直せる）。今週・今月の達成率、連続・最長の日数、項目ごとの直近30日の達成率、数値の項目の推移グラフ
- **ルーティン**: 項目の追加・編集・並べ替え・休止・削除。やる曜日を選べる（練習日とオフの日で中身を変えられる）

```bash
npm run dev:routine      # 開発サーバー
npm run build:routine    # 本番ビルド（dist-routine/）
npm run preview:routine  # ビルド結果の確認
```

ソースは `routine/`、ビルド設定は `vite.routine.config.ts`。ボタンやシートなどの部品と色・フォントは GRIND の `src/` から読み込みます（GRIND 側は変えていません）。テストは `npm test` で GRIND と一緒に走ります。

- 設計: `docs/superpowers/specs/2026-10-30-routine-app-design.md`
